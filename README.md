# Viva Bem

Landing page educacional sobre saúde preventiva, vacinação e acesso a informações públicas confiáveis. O projeto apresenta cuidados em diferentes fases da vida e incentiva decisões compartilhadas com profissionais de saúde.

> Este projeto tem finalidade exclusivamente educacional. O conteúdo não substitui consulta, diagnóstico ou orientação individual de profissionais de saúde e não representa uma instituição em atividade.

## Funcionalidades

- Navegação interna para as seções de prevenção feminina e masculina.
- Menu responsivo e acessível em dispositivos móveis.
- Apresentação de informações preventivas por faixa etária.
- Alertas educativos sobre saúde, vacinação e atenção a sintomas.
- Links para fontes oficiais do Ministério da Saúde e do INCA.
- Imagens otimizadas em WebP.
- Layout adaptado para desktop, tablet e celular.
- Ano do rodapé atualizado automaticamente.

## Tecnologias

- HTML5 semântico.
- CSS3 e Sass/SCSS.
- JavaScript.
- HTML Validate.
- GitHub Actions.

## Executar localmente

```bash
git clone https://github.com/jessicatrindadeads/projetovivabem.git
cd projetovivabem
npm install
npm run build
```

Abra `index.html` no navegador ou utilize um servidor estático de sua preferência.

## Validação

```bash
npm run check
npm run build
```

O GitHub Actions valida o HTML, compila os estilos SCSS e verifica se o CSS publicado corresponde ao código-fonte versionado.
